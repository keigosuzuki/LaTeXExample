# LaTeX Templates

各種文書作成用の LaTeX テンプレート集です。
各テンプレートの preamble は基本的な構成になっているため、用途に応じて適宜パッケージを追加・調整して使用してください。

## 各ディレクトリの説明

### `eeis/`
電気系輪講・学内ゼミ発表用の資料テンプレート。

### `faq/`
LaTeX に関する基本的な解説・コンパイル手順・FAQ ドキュメント。

### `preamble/`
用途別プリアンブル（スタイル設定）の `.sty` サンプル集。

### `thesis/`
卒業論文・修士論文・博士論文および要約（Abstract）用のテンプレート集。
